Games@Cloud

Request

Grid size ≥ 10; agents per team ≤ grid size. Each team chases grid size ÷ 2 flags.

Shuffles use a fixed seed (42), so equal parameters always give the same board.

The map must exist in the server's gameoflife/src/main/resources.

Result

Pick a game, set its parameters and send a request.

Light requests are usually served by Lambda; heavy ones by an EC2 worker.
